One line from your future self: the password you just changed is the one you'll forget at 3 a.m. in 2031, and the reset link goes to an email you deleted.

The line is 139 characters, inside the competition's 1–200 character, single-line gate. Running `main.py` validates it first (not blank, one line only, length inside the gate) and then writes it verbatim to `/output/entry.txt` and prints it.

## Run it

```sh
python3 main.py
```
